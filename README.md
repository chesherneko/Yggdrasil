# Yggdrasil

`이그드라실`은 주사위를 굴려 보드를 돌며 영토를 차지하는 2~4인 온라인 보드게임입니다.<br/>
부루마블처럼 영토를 사고 건물을 올려 자산을 늘리고, 상대 영토에서는 1:1 실시간 대전 **야차**로 땅을 빼앗을 수 있습니다.

## 게임 소개

북유럽 신화를 배경으로, 플레이어는 36칸 보드를 돌며 영토를 사고 **건물**과 **랜드마크**를 올려 통행료를 키웁니다.<br/>
어떤 땅에 투자할지, 상대 영토에서 싸움을 걸지 말지를 판단하는 것이 중요합니다.

상대 영토에 도착하면 통행료를 낸 뒤 **야차**를 신청할 수 있습니다. 야차는 30초 동안 펼쳐지는 1:1 횡스크롤 대전으로, 이기면 그 영토를 건물째 빼앗고 지면 통행료를 한 번 더 냅니다.<br/>
방어자는 확률에 걸고 결투를 거절할 수 있지만, 거절에 성공할 때마다 다음 거절 확률이 절반으로 줄어듭니다. 랜드마크가 지어진 영토에는 야차를 걸 수 없습니다.

보드에는 영토 외에도 무작위 효과가 나오는 **황금카드**, 2턴 동안 묶이는 **감옥**, 장비를 얻는 **보물창고**, 원하는 칸으로 이동하는 **비프로스트**, 지나가기만 해도 들를 수 있는 **상점**이 있습니다. 상점과 보물창고에서 얻은 장비는 야차에서 스킬로 사용합니다.<br/>
돈이 모자라면 가치가 낮은 영토부터 자동으로 급매되고, 게임당 한 번은 **까방권**으로 지불을 면제받을 수 있습니다.

다른 플레이어가 모두 파산하거나 최대 라운드가 끝났을 때, 총자산(현금 + 영토 가치)이 가장 높은 플레이어가 승리합니다.

## 조작법

### 보드

| 조작 | 설명 |
| --- | --- |
| 닉네임·방 코드 입력 후 입장 | 같은 방 코드를 입력한 플레이어끼리 한 방에 모입니다. |
| 주사위 버튼 클릭 | 자기 턴에 주사위 2개를 굴려 나온 눈만큼 이동합니다. |
| 마우스 왼쪽 클릭 | 구매 팝업, 상점, 결투 신청·수락 등 화면의 선택지를 고릅니다. |
| 황금카드 클릭 | 자기 턴에 뽑힌 카드를 뒤집어 효과를 확인합니다. |
| 비프로스트에서 칸 클릭 | 클릭한 칸으로 이동합니다. |

### 야차 (전투)

| 조작 | 설명 |
| --- | --- |
| A / D 또는 ← / → | 좌우로 이동합니다. |
| Space | 누르고 있는 방향으로 빠르게 회피합니다. 회피하는 동안에는 공격을 받지 않으며, 다시 쓰려면 잠시 기다려야 합니다. |
| 1 ~ 5 | 해당 슬롯의 장비 스킬을 사용합니다. 장비마다 재사용 대기시간이 있습니다. |
